# 数据中心入行书（初稿存档）

作者：Guangyi Zhao（赵广义）

一本写给想入行数据中心行业的人的原创入行书：从数据中心是什么、产业链怎么赚钱，到供配电、制冷、机柜与服务器、网络与布线，再到建设交付、测试、运维、监控自动化，最后落到岗位地图与技能树。本仓为**初稿存档**，不是定稿。

## 状态说明（务必先读）
